# AGE 动漫 Yingxia JS（v1 基础 + 地区分类，无重复今日推荐）

## 分类

1. 最新更新
2. 日本
3. 中国
4. 欧美

Yingxia 原生「推荐」仍通过 `homeVod()` 请求 AGE 首页推荐内容，不单独暴露“今日推荐”分类。

## 地区筛选

日本、中国、欧美各自显示五个筛选项：

- 类型：全部、TV、剧场版、OVA
- 年份：全部、2026 至 2001、2000以前
- 季度：全部、第一至第四季度
- 状态：全部、连载、完结
- 排序：时间、热度

目录 URL 的其他筛选字段固定为 `all`：字母、题材和资源。地区来自分类，页码来自分页参数。

## 网络错误处理补丁

- 首页推荐 `homeVod()` 的请求失败时记录错误并返回空推荐列表，避免首页推荐请求失败导致整站显示插件错误。
- `request()` 增加请求异常与响应字段日志；当宿主返回空状态码时，会尽量显示宿主提供的 `error/message/msg` 诊断信息。
- 首页请求的 User-Agent 改为移动 Safari，并补充常规 HTML Accept、Accept-Language、Cache-Control 请求头。
- 不再使用 Node `require()`，维持 iOS QuickJS 兼容方向。

注意：这组改动不能绕过 AGE 服务器的 Cloudflare 或网络限制。如果 AGE 对 Yingxia 的原生 HTTP 请求返回 403、TLS/DNS 失败或空状态码，`homeVod()` 会显示空推荐；地区目录、最新更新、搜索仍需要服务器允许请求才能返回内容。

## 保留

详情页解析、集数提取、五洲派播放页提取、Go WASM 解密实现及 `play()` 逻辑保留。iOS QuickJS 是否具备 WebAssembly 支持仍需设备实测。

## 当前验证

已通过 JS 语法检查、订阅 JSON 检查和模拟宿主网络失败测试。模拟测试确认首页推荐请求失败时 `homeVod()` 返回 `{ list: [] }`，首页分类仍为“最新更新、日本、中国、欧美”。未完成 iOS 真机网络验证。
